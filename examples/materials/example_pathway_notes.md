# 示例机制材料（SYNTHETIC EXAMPLE — **非组织方正式案例材料**）

> 本文件属于 Skill 的 `examples/`，是为演示「材料 → 可编辑图稿 → 导出件」调用链路而**合成**的材料。
> 其中的分子名（`EXL1`/`EXR1`/`EXK1`/`EXTF1`/`EXG1`/`EXP1`）、通路与数值都不是真实实验数据，
> **不得**被当作任何正式案例（包括组织方的 figure03）的材料或答案。

## 1. 配体与受体

胞外配体 EXL1 与质膜受体 EXR1 结合。
EXR1 是跨膜受体，其胞外域朝向胞外，胞内域朝向胞质。

## 2. 胞内信号

EXR1 激活胞质激酶 EXK1。
EXK1 磷酸化胞质转录因子 EXTF1。
磷酸化的 EXTF1 转运入核，形成核内转录因子 EXTF1（nuclear）。

## 3. 转录与翻译

核内 EXTF1（nuclear）激活基因 EXG1 的转录。
EXG1 翻译为效应蛋白 EXP1。

## 4. 负反馈

效应蛋白 EXP1 对胞质激酶 EXK1 形成负反馈抑制。

## 5. 证据强度

EXR1 激活 EXK1 的证据强度为 high。
EXK1 磷酸化 EXTF1 的证据强度为 medium。
EXTF1（nuclear）激活基因 EXG1 转录的证据强度为 low。
EXG1 翻译为 EXP1 的证据强度为 low。
EXP1 对 EXK1 的负反馈证据强度为 medium。

## 6. 图例与编码

线宽编码证据强度：high 为 1.4 pt，medium 为 1.0 pt，low 为 0.6 pt。
关系线型编码：结合为无箭头实线，激活为实线箭头，修饰为虚线箭头，转运为跨边界箭头，转录与翻译为实线箭头，反馈为虚线。
